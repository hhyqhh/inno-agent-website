# 创建你的第一个工作区

本教程以「雅思备考」为例，带你跑通完整流程。

## 1. 新建工作区

在界面中点击「新建工作区」，填入名称如 `ielts-prep`。

![新建工作区](/images/docs/01_new_workspace.png)

## 2. 编写 agent.md

工作区的 `agent.md` 定义了 Agent 的角色与上下文：

```markdown
# 雅思备考助手

## 学习者背景
- 目标分数：7.0
- 薄弱项：口语 Part 2/3
- 备考时间：2 个月

## Agent 职责
- 每日提供口语话题练习
- 对回答进行评分和改进建议
- 积累高频词汇与表达
```

## 3. 添加 Skill

从 [Skill 库](https://github.com/Chloris-Blaxk/inno-agent-hub/tree/main/skill-library) 下载需要的 Skill 包，上传到工作区。

![上传 Skill](/images/docs/03_skill_uploaded.png)

## 4. 开始对话

一切就绪！现在可以和你的专属雅思 Agent 对话了。
